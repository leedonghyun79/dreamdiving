# 드림다이브 소개 페이지 디자인 스펙

## 개요
드림다이브(Dream Dive) 회사 소개 페이지(`/about`)의 완전한 웹 디자인. 데모 이미지("업체 소개.png")의 레이아웃을 기반으로 구성.

## 페이지 구조

### 1. 히어로 섹션
- **구성**: 풀 너비 배경 이미지 (다이버 활동 이미지)
- **높이**: 약 300-350px
- **레이아웃**: 이미지 only (텍스트 오버레이 없음)
- **이미지 처리**: placeholder로 border div 사용

### 2. 메인 소개 섹션
- **레이아웃**: 2컬럼 (텍스트 좌측 + 이미지 우측)
- **좌측 (텍스트)**:
  - 섹션 제목: "DREAM DIVE" (큰 폰트, 파란색)
  - 부제목: "드림다이브 소개" 또는 유사
  - 본문 텍스트: 3-4줄의 회사 설명
  - 여러 문단으로 구성 가능
- **우측 (이미지)**:
  - 다이버 관련 이미지 (가로 긴 이미지)
  - placeholder: border div
- **간격**: 여유 있는 패딩

### 3. BSAC 섹션
- **배경**: 검은색 (다크 배경)
- **레이아웃**: 가운데 정렬
- **콘텐츠**:
  - 흰색 텍스트: "The Spirit of BSAC"
  - BSAC 로고/이미지 (가운데)
  - 로고 아래: "www.bsac.com" 텍스트
- **높이**: 약 250-300px
- **패딩**: 상하좌우 여유 있게

### 4. 프로그램/특징 섹션
- **레이아웃**: 2x2 그리드 (4개 이미지 카드)
- **각 카드**:
  - 정사각형 또는 16:9 비율 이미지
  - placeholder: border div + 텍스트 레이블 (선택사항)
  - hover 효과: 약간의 확대 또는 그림자
- **간격**: 카드 간 일정한 gap
- **반응형**: 모바일에서는 1컬럼, 태블릿 2컬럼, 데스크톱 2x2

### 5. 푸터
- **구성**: 기존 Footer 컴포넌트 재사용
- **위치**: 페이지 최하단

## 스타일 가이드

### 색상
- 주색: 파란색 (#0066CC 또는 유사)
- 배경: 흰색
- BSAC 섹션: 검은색 (#1a1a1a 또는 유사)
- 텍스트: 검은색 (#333333), 흰색

### 타이포그래피
- 제목 폰트: Noto Sans KR Bold (가변 폰트 사용)
- 본문 폰트: Noto Sans KR Regular
- 제목 크기: 32-48px
- 본문 크기: 14-16px
- 라인 높이: 1.6-1.8

### 여백/레이아웃
- 섹션 상하 패딩: 60-80px
- 좌우 마진: 반응형 (모바일 20px, 데스크톱 50-100px)
- 2컬럼 간격: 40-60px

### 이미지 처리
- 모든 이미지 자리는 border div로 표시
- 배경색: light gray (#f0f0f0)
- border 색상: #cccccc
- border 굵기: 2px
- 최소 높이: 명확한 영역 표시

## 반응형 디자인
- **모바일 (< 768px)**:
  - 2컬럼 섹션 → 1컬럼 (텍스트 위, 이미지 아래)
  - 이미지 그리드 → 1컬럼
  - 섹션 패딩 감소 (20px)

- **태블릿 (768px - 1024px)**:
  - 2컬럼 유지
  - 이미지 그리드 → 2컬럼
  - 적절한 여백 조정

- **데스크톱 (> 1024px)**:
  - 현재 디자인 그대로

## 기술 구현
- **프레임워크**: Next.js 16.2.1
- **스타일링**: Panda CSS
- **이미지**: public 폴더 또는 border placeholder div
- **컴포넌트**: 기존 components 재사용 (Header, Footer 등)

## 파일 위치
- **페이지**: `src/app/about/page.tsx`
- **스타일**: Panda CSS inline 또는 별도 css.ts 파일
